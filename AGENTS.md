# Правила работы в проекте

## Git-ветки

- Никогда не создавать новые Git-ветки в этом проекте без прямого указания пользователя на создание новой ветки.
- Запросы на правки, исправления, коммит, push, слияние или релиз сами по себе не разрешают создавать новую ветку. По умолчанию продолжать работу в текущей ветке.
