# 1.0.1

Choose excluded folders from suggestions and manage them as removable chips.

- Search vault folders while typing and select a suggestion to add an exclusion.
- Click a folder chip to remove its exclusion. Changes apply and save immediately.
- Add a future folder by entering its vault-relative path and clicking **Add folder**.
- Preserve existing exclusions, keep the default list empty, and support commas and semicolons in folder names.
- Clarify in both user guides that Folder Guard is an add-on for Paste image rename.

Requires Paste image rename to be installed and enabled separately. Manual batch renaming is unaffected. Wait for the connected status after enabling or reloading the dependency before importing attachments.
