# 1.0.0

Initial release of Paste Image Rename Folder Guard.

- Exclude selected vault folders and their subfolders from Paste image rename's automatic prompts and renaming.
- Start with an empty exclusion list and choose which folders to protect.
- Preserve compatibility with the temporary helper's saved exclusions.
- Show connection status and invalid folder rules in settings.
- Restore the original handler when disabled and reconnect after dependency reloads.

Requires Paste image rename to be installed and enabled separately. Manual batch renaming is unaffected. Wait for the connected status after enabling or reloading the dependency before importing attachments.
